## 🚀 Quick Start / Local Setup

No build tools or heavy dependencies required. Built with pure modern HTML5, Vanilla CSS, and JavaScript.

Simply double click `index.html` or run with any local HTTP server:

```bash
# Using Python
python -m http.server 3000

# Using Node.js
npx serve
```

Visit `http://localhost:3000` in your browser.
